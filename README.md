## 📖 About The Project

This portfolio is designed to be **fast, modern, and easy to maintain**. It separates the public-facing site from the admin panel, allowing content updates (like experience and projects) without touching a single line of code.

## ✨ Features

| Feature | Description |
| :--- | :--- |
| 🎨 **Modern UI** | Clean, responsive design optimized for all devices. |
| ⚡ **Dynamic Content** | Portfolio data loads dynamically via `data-loader.js`. |
| 🔐 **Admin Panel** | Manage content (e.g., Experience Editor) through `admin.html` — no coding required. |
| 🎬 **Interactive Elements** | Smooth animations and transitions powered by `script.js`. |
| 🏢 **Company Logos** | Includes SVG assets for Microsoft, ServiceNow, and more. |
